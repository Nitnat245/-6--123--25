## Файл `memory.py` - работа с данными

Этот файл отвечает за хранение и обработку данных студентов. Здесь живут все функции, которые работают с базой данных.

### Функция `create_record`

Добавляет нового студента в базу данных.

**Что делает:**
- Проверяет, что возраст не отрицательный
- Проверяет, что нет студента с таким же номером
- Проверяет, что имя и фамилия не пустые
- Проверяет, что пол указан правильно (М или Ж)
- Делает первую букву имени и фамилии большой
- Добавляет студента в общий список

### Функция `select_record`

Ищет студентов по разным параметрам.

**Что делает:**
- Если ничего не искать, показывает всех студентов
- Можно искать по одному полю или сразу по нескольким
- Поиск работает без разницы, большие буквы или маленькие

### Функция `update_record`

Меняет данные у существующего студента.

**Что делает:**
- Ищет студента по его номеру
- Если студент найден, меняет только те поля, которые указали
- Остальные поля остаются как были
- Проверяет новые данные на правильность

### Функция `delete_record`

Удаляет студентов из базы данных.

**Что делает:**
- Удаляет студентов, которые подходят под условия
- Можно удалить одного или всех подходящих
- Сначала находит, кого удалять, потом удаляет

## Файл `tui.py` - пользовательский интерфейс

Этот файл отвечает за то, как программа общается с человеком. Подключает функции из `memory.py`.

**Что делает:**
- В начале файла берёт готовые функции для работы с данными
- Каждый раз, когда программа ждёт действия, рисует на экране меню
- Обрабатывает ввод пользователя
- Показывает результаты работы

---

## Файл `__main__.py` - запуск программы

Этот файл нужен, чтобы программу можно было запустить. Вызывает функцию `run()`, которая показывает меню.
